# Web 开发

进两年来，Agent 的快速发展，让 Web 开发的门槛变得非常低，一个从未学习过变成的人，也可以开发出属于自己的优秀的项目，其中大量的就是 Web 项目。

尽管这些 Vibe coding 项目可能在实现细节上存在或大或小，或多或少的问题。 但这给我仍然给我一个警示！

在 Codex、Claude 等一众 Agent 大放异彩的时代，如果还是做一些没有价值的工作——CRUD、调 api 等，只能连汤都喝不上。

但要知道未来的路如何走下去也不太可能，时代的变化是巨大的，我认为现在较为底层的知识和技能还比较有价值。

同时，对于 Java 的相关技术栈也不能荒废了，现如今这个生态仍然是国内占比最大的一块。

关于 Java，现在融合了 Agent 相关生态，是一种比较好的趋势，说明 Java 还是不可缺乏的，Spring 和 SpringBoot 是基本，肯定是需要进行复盘的。

然后是微服务和系统架构设计，软件工程专业，架构能力是必须具备的。

所以先复盘 Spring，然后进入 SpringBoot，最后进行 Agent 开发学习。

在保证了 Web 后端开发能力的基础上融合 Agent 相关生态技术，研一期间暂时就这样安排吧，在技术层面。
